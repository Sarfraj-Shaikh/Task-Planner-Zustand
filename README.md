## 📌 About the Project

This is a Task Planner Website built using **ReactJS**. The project demonstrates how to create a task management interface and use **Zustand** for state management and storing application data within the React application.

The main goal of this project was to build a practical ReactJS project during a live coding session and demonstrate the use of Zustand in a real-world application.
